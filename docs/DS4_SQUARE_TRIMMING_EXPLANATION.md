# DS4 项目方形裁剪（Square Trimming）详细解释

## 一、背景与目的

### 1.1 问题背景

在摇杆外圈校准中，校准数据以**极坐标形式**存储：
- **数据结构**：48个半径值（radius），每个值代表该角度方向的最大允许半径
- **数据范围**：理论上半径值可以是任意正数（0.0 到 ∞）
- **实际限制**：游戏手柄协议要求输出值在 **[-1, 1]** 范围内

### 1.2 为什么需要裁剪？

当校准后的摇杆点位值超出 [-1, 1] 范围时：
- **物理上**：摇杆可能确实移动到了超出标准范围的位置
- **协议上**：游戏手柄协议不允许输出值超出 [-1, 1]
- **需要**：将超出范围的值裁剪到有效范围内

### 1.3 为什么使用"方形裁剪"而不是"圆形裁剪"？

- **方形裁剪**：将值限制在 **[-1, -1] 到 [1, 1]** 的方形区域内
- **圆形裁剪**：将值限制在半径为 1 的圆形区域内

**选择方形裁剪的原因**：
1. **保持方向性**：方形裁剪后，摇杆的方向（角度）保持不变
2. **符合协议**：游戏手柄协议通常使用方形边界（X和Y轴独立限制）
3. **简单高效**：只需对X和Y分别进行clamp操作

## 二、方形裁剪的详细步骤

### 2.1 函数签名与输入

```javascript
_trimCircularityDataToSquare(data)
```

**输入参数**：
- `data`: 数组，包含48个半径值（极坐标形式）
- 每个值 `data[i]` 表示角度 `i * (2π / 48)` 方向的最大半径

**示例输入**：
```javascript
data = [0.95, 0.98, 1.05, 1.02, ...]  // 48个半径值
// 索引0对应角度 -180°（或180°）
// 索引1对应角度 -172.5°
// ...
```

### 2.2 步骤1：计算角度

```javascript
const angle = (i * 2 * Math.PI) / numSectors;
```

**说明**：
- `i`: 当前索引（0 到 47）
- `numSectors`: 扇区数量（48）
- `angle`: 该索引对应的角度（弧度制）

**角度映射**：
- 索引 0 → 角度 -180°（或 180°）
- 索引 12 → 角度 -90°（或 270°）
- 索引 24 → 角度 0°
- 索引 36 → 角度 90°

**示例**：
```javascript
i = 0:  angle = 0 * 2π / 48 = 0 rad = 0° (实际是 -180° 或 180°)
i = 12: angle = 12 * 2π / 48 = π/2 rad = 90° (实际是 -90° 或 270°)
i = 24: angle = 24 * 2π / 48 = π rad = 180° (实际是 0°)
i = 36: angle = 36 * 2π / 48 = 3π/2 rad = 270° (实际是 90°)
```

### 2.3 步骤2：极坐标转笛卡尔坐标

```javascript
const x = radius * Math.cos(angle);
const y = radius * Math.sin(angle);
```

**转换公式**：
- `x = r * cos(θ)`
- `y = r * sin(θ)`

**说明**：
- `radius`: 当前索引的半径值（极坐标）
- `angle`: 当前索引的角度（弧度）
- `x, y`: 转换后的笛卡尔坐标

**示例**：
```javascript
// 假设索引24（角度0°，即右侧），半径1.2
radius = 1.2
angle = 24 * 2π / 48 = π rad = 180°（实际是0°）

x = 1.2 * cos(π) = 1.2 * (-1) = -1.2  // 注意：这里角度映射可能有问题
y = 1.2 * sin(π) = 1.2 * 0 = 0

// 实际上，如果索引24对应0°（右侧）：
x = 1.2 * cos(0) = 1.2 * 1 = 1.2
y = 1.2 * sin(0) = 1.2 * 0 = 0
```

**注意**：代码中的角度计算可能需要根据实际映射调整。

### 2.4 步骤3：方形裁剪（核心步骤）

```javascript
const trimmedX = Math.max(-1, Math.min(1, x));
const trimmedY = Math.max(-1, Math.min(1, y));
```

**裁剪逻辑**：
- `Math.min(1, x)`: 如果 x > 1，则限制为 1；如果 x < -1，则保持原值
- `Math.max(-1, ...)`: 如果 x < -1，则限制为 -1；如果 x > 1，则保持原值（已被上一步限制）

**等价写法**：
```javascript
const trimmedX = x > 1 ? 1 : (x < -1 ? -1 : x);
const trimmedY = y > 1 ? 1 : (y < -1 ? -1 : y);
```

**可视化示例**：

```
原始坐标 (x, y) = (1.2, 0.8)
         ↓
裁剪后 (trimmedX, trimmedY) = (1.0, 0.8)

原始坐标 (x, y) = (0.9, 1.3)
         ↓
裁剪后 (trimmedX, trimmedY) = (0.9, 1.0)

原始坐标 (x, y) = (1.5, 1.5)  // 超出方形边界
         ↓
裁剪后 (trimmedX, trimmedY) = (1.0, 1.0)  // 裁剪到方形角点
```

**方形边界示意图**：

```
        y
        ↑
        |
   1.0  |  ┌─────┐
        |  │     │
   0.0  |  │  ●  │  ← 原始点 (1.2, 0.8)
        |  │     │     裁剪后 (1.0, 0.8)
  -1.0  |  └─────┘
        |
        └──────────────→ x
      -1.0   0.0   1.0
```

### 2.5 步骤4：转回极坐标

```javascript
const trimmedRadius = Math.sqrt(trimmedX * trimmedX + trimmedY * trimmedY);
data[i] = trimmedRadius;
```

**转换公式**：
- `r = √(x² + y²)`

**说明**：
- 将裁剪后的笛卡尔坐标转换回极坐标（半径）
- 更新原始数据数组

**示例**：
```javascript
// 原始：radius = 1.2, angle = 0°
// 转换：x = 1.2, y = 0
// 裁剪：trimmedX = 1.0, trimmedY = 0
// 转回：trimmedRadius = √(1.0² + 0²) = 1.0

// 原始：radius = 1.5, angle = 45°
// 转换：x = 1.5 * cos(45°) ≈ 1.06, y = 1.5 * sin(45°) ≈ 1.06
// 裁剪：trimmedX = 1.0, trimmedY = 1.0
// 转回：trimmedRadius = √(1.0² + 1.0²) = √2 ≈ 1.414
```

## 三、完整流程示例

### 3.1 示例1：单个值超出范围

**输入数据**：
```javascript
data = [1.2, 0.95, 0.98, ...]  // 索引0的半径值为1.2（超出1.0）
i = 0
```

**处理过程**：

1. **计算角度**：
   ```javascript
   angle = 0 * 2π / 48 = 0 rad = 0°（假设对应右侧）
   ```

2. **极坐标转笛卡尔**：
   ```javascript
   x = 1.2 * cos(0) = 1.2 * 1 = 1.2
   y = 1.2 * sin(0) = 1.2 * 0 = 0
   ```

3. **方形裁剪**：
   ```javascript
   trimmedX = Math.max(-1, Math.min(1, 1.2)) = Math.max(-1, 1) = 1.0
   trimmedY = Math.max(-1, Math.min(1, 0)) = Math.max(-1, 0) = 0
   ```

4. **转回极坐标**：
   ```javascript
   trimmedRadius = √(1.0² + 0²) = 1.0
   data[0] = 1.0  // 更新为裁剪后的值
   ```

**结果**：半径从 1.2 裁剪到 1.0，方向保持不变（仍然是右侧，0°）

### 3.2 示例2：对角线方向超出范围

**输入数据**：
```javascript
data = [..., 1.5, ...]  // 索引对应45°方向，半径1.5
i = 某个索引（假设对应45°）
```

**处理过程**：

1. **计算角度**：
   ```javascript
   angle = i * 2π / 48 = 45° = π/4 rad
   ```

2. **极坐标转笛卡尔**：
   ```javascript
   x = 1.5 * cos(π/4) = 1.5 * (√2/2) ≈ 1.061
   y = 1.5 * sin(π/4) = 1.5 * (√2/2) ≈ 1.061
   ```

3. **方形裁剪**：
   ```javascript
   trimmedX = Math.max(-1, Math.min(1, 1.061)) = 1.0
   trimmedY = Math.max(-1, Math.min(1, 1.061)) = 1.0
   ```

4. **转回极坐标**：
   ```javascript
   trimmedRadius = √(1.0² + 1.0²) = √2 ≈ 1.414
   data[i] = 1.414
   ```

**结果**：
- 原始半径：1.5
- 裁剪后半径：1.414（√2）
- 方向：保持45°不变
- **注意**：裁剪后的半径小于原始半径，但大于1.0（因为在对角线上）

## 四、方形裁剪的数学原理

### 4.1 方形边界 vs 圆形边界

**方形边界**（使用的方法）：
- 边界方程：`|x| ≤ 1` 且 `|y| ≤ 1`
- 边界形状：正方形
- 最大半径：在对角线上为 √2 ≈ 1.414

**圆形边界**（未使用）：
- 边界方程：`x² + y² ≤ 1`
- 边界形状：圆形
- 最大半径：所有方向都是 1.0

### 4.2 为什么方形裁剪后半径可能 > 1.0？

**关键理解**：
- 方形裁剪限制的是 **X和Y坐标**，而不是半径
- 在对角线方向（45°, 135°, 225°, 315°），裁剪后的点可能在方形的角上
- 方形角点的半径 = √(1² + 1²) = √2 ≈ 1.414

**示例**：
```
原始点：半径1.5，角度45°
  → (x, y) = (1.061, 1.061)
  → 裁剪后：(1.0, 1.0)
  → 半径 = √2 ≈ 1.414

原始点：半径1.2，角度0°（右侧）
  → (x, y) = (1.2, 0)
  → 裁剪后：(1.0, 0)
  → 半径 = 1.0
```

### 4.3 方向保持性

**重要特性**：
- 方形裁剪**保持方向（角度）不变**
- 只改变半径（距离）

**数学证明**：
```
原始点：角度θ，半径r
  → (x, y) = (r*cos(θ), r*sin(θ))

裁剪后：
  → (x', y') = (clamp(r*cos(θ)), clamp(r*sin(θ)))
  → 角度θ' = atan2(y', x') = atan2(clamp(r*sin(θ)), clamp(r*cos(θ)))

如果x和y都未超出范围：
  → θ' = θ（方向不变）

如果x或y超出范围：
  → 方向可能改变（取决于哪个轴被裁剪）
```

**实际效果**：
- 在**轴向方向**（0°, 90°, 180°, 270°）：方向完全保持
- 在**对角线方向**（45°, 135°, 225°, 315°）：方向保持，但半径被限制到√2
- 在**其他方向**：方向可能略有改变（取决于哪个轴先达到边界）

## 五、优缺点分析

### 5.1 优点

1. **保持方向性**：在大多数情况下，摇杆的方向（角度）保持不变
2. **符合协议**：游戏手柄协议通常使用方形边界限制
3. **简单高效**：只需对X和Y分别进行clamp操作
4. **可预测性**：裁剪结果容易理解和预测

### 5.2 缺点

1. **对角线方向半径 > 1.0**：裁剪后，对角线方向的半径可能达到√2 ≈ 1.414，仍然超出标准范围
2. **方向可能改变**：在某些情况下（特别是接近方形角点），方向可能略有改变
3. **不对称性**：不同方向的裁剪效果不同（轴向 vs 对角线）

### 5.3 潜在问题

**问题1：对角线方向仍然超出范围**
```
原始：半径1.5，角度45°
裁剪后：半径√2 ≈ 1.414
结果：仍然 > 1.0，可能不符合某些协议要求
```

**解决方案**（如果需要）：
- 可以再次进行圆形裁剪：`if (trimmedRadius > 1.0) trimmedRadius = 1.0`
- 但这会改变方向，失去方形裁剪的优势

**问题2：方向改变**
```
原始：半径1.2，角度30°
  → (x, y) = (1.039, 0.6)
  → 裁剪后：(1.0, 0.6)
  → 角度 = atan2(0.6, 1.0) ≈ 31°（略有改变）
```

## 六、与GP2040-CE的对比

### 6.1 GP2040-CE的处理方式

```cpp
// 直接clamp归一化值
x_value = std::clamp(x_value, ANALOG_MINIMUM, ANALOG_MAX);  // [0.0, 1.0]
y_value = std::clamp(y_value, ANALOG_MINIMUM, ANALOG_MAX);  // [0.0, 1.0]
```

**特点**：
- 直接限制X和Y坐标
- 范围：[0.0, 1.0]（而不是 [-1, 1]）
- 简单直接，不涉及坐标转换

### 6.2 对比总结

| 特性 | DS4（方形裁剪） | GP2040-CE（直接clamp） |
|------|----------------|----------------------|
| **输入格式** | 极坐标（半径数组） | 笛卡尔坐标（x, y值） |
| **处理方式** | 极坐标→笛卡尔→裁剪→极坐标 | 直接clamp |
| **方向保持** | 大部分情况下保持 | 完全保持 |
| **复杂度** | 较高（需要坐标转换） | 较低（直接操作） |
| **对角线问题** | 可能 > 1.0 | 无此问题 |
| **适用范围** | 极坐标数据 | 笛卡尔坐标数据 |

## 七、总结

### 7.1 核心思想

DS4的方形裁剪方法：
1. **将极坐标数据转换为笛卡尔坐标**
2. **在笛卡尔坐标系中进行方形裁剪**（限制X和Y到[-1, 1]）
3. **转换回极坐标**，得到裁剪后的半径

### 7.2 关键理解

- **不是直接裁剪半径**，而是裁剪X和Y坐标
- **保持方向性**是主要目标
- **对角线方向**可能仍然超出标准范围（√2 ≈ 1.414）

### 7.3 适用场景

- **极坐标数据**：校准数据以极坐标形式存储
- **需要保持方向**：希望裁剪后尽可能保持原始方向
- **协议允许**：如果协议允许对角线方向半径 > 1.0

### 7.4 改进建议

如果需要严格限制半径 ≤ 1.0：
```javascript
// 在转回极坐标后，再次检查
const trimmedRadius = Math.sqrt(trimmedX * trimmedX + trimmedY * trimmedY);
if (trimmedRadius > 1.0) {
  // 进行圆形裁剪：按比例缩小
  const scale = 1.0 / trimmedRadius;
  const finalX = trimmedX * scale;
  const finalY = trimmedY * scale;
  data[i] = Math.sqrt(finalX * finalX + finalY * finalY);  // 应该等于1.0
} else {
  data[i] = trimmedRadius;
}
```

但这会改变方向，失去方形裁剪的优势。
